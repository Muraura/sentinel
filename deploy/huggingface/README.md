# Sentinel

Ask a security question and watch an AI agent investigate it step by step: it chooses which evidence to gather
(logins, badge access, device status, application logs), correlates it into a timeline, and writes a report in
which every fact cites evidence. It can propose remediation, but cannot execute it: a human must approve.

All data is synthetic. Code and design notes: see the GitHub link on the page.
